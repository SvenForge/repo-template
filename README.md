# [Repo Template](https://gitlab.com/sventerprise/repo-template)

Common [copier](https://copier.readthedocs.io/en/stable/) template to setup new or update existing Git repositories. Batteries included.

## Getting started

### Installation

Install the supported Copier release:

```shell
python -m pip install "copier==9.17.2"
```

### Usage

Render the template interactively from this repository:

```shell
copier copy . path/to/new-project
```

### Development

Use one of the supported development environments:

* Open this repository in its included [development container](.devcontainer/devcontainer.json). VS Code with the Dev Containers extension is recommended for creating and accessing the container.
* Start a task in [Codex Cloud](https://chatgpt.com/codex/cloud) using the preconfigured environment for this repository.
