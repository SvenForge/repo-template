# Sphinx

Generate project documentation with Sphinx and MyST Markdown, with optional API and requirements tracking. The host supplies metadata, available Python packages, and dependency/install integrations.

## Questions and choices

| Answer | Decision |
| --- | --- |
| `sphinx_api_packages` | Which available Python packages need generated API documentation. Asked only when the host supplies packages; all available packages are selected by default. |
| `sphinx_needs` | Whether to enable Sphinx-Needs for requirements tracking; defaults to false. |
| `sphinx_needs_pages` | When Needs is enabled, select requirements, architecture, implementation, and verification pages; all four are selected by default. |

## After generation

Replace the TODO in `doc/notes.md` and write content for any selected Needs pages. Review API package selection and documentation metadata. Keep README toctree markers when using the README as the landing page; the index also works without a README.

Install the host's documentation dependencies, for example `python -m pip install --group dev` when that group is supplied, adding `--editable .` for an installable distribution. Build with:

```shell
make -C doc/sphinx html SPHINXOPTS='-W --keep-going'
```

Open `doc/sphinx/_build/html/index.html`. See [Sphinx's documentation](https://www.sphinx-doc.org/en/master/) for authoring/build details.

## Reuse reference

Supply `sphinx_inputs` after including the module. See the [module guide][module-guide] for precedence, path rules, and manifest conventions.

### Input variables

| Input | Type | Standalone fallback and role |
| --- | --- | --- |
| `enabled` | bool | `true`; direct activation. |
| `repository_name`, `owner_name` | str | `My Repository`, empty; direct documentation metadata. |
| `year` | int | Current year; direct metadata override. |
| `has_readme`, `has_license` | bool | `false`; direct switches for index links. |
| `python_packages` | list[str] | Empty; available API choices. |
| `api_packages` | list[str] | All available `python_packages`; question default override. |
| `needs` | bool | `false`; question default. |
| `needs_pages` | list[str] | `requirements`, `architecture`, `implementation`, `verification`; question default. |

### Output variables

Fields in `sphinx.vars`:

| Variable | Type | Meaning |
| --- | --- | --- |
| `enabled` | bool | Effective activation. |
| `repository_name`, `owner_name` | str | Effective documentation metadata. |
| `year` | int | Effective supplied or current year. |
| `has_readme`, `has_license` | bool | Host-supplied availability of index-link destinations. |
| `python_packages` | list[str] | Host-supplied available API packages. |
| `api_packages` | list[str] | Answered API-package selection. |
| `needs` | bool | Answered Sphinx-Needs activation. |
| `needs_pages` | list[str] | Answered selection of Needs pages. |

### Generated files

| Path | Condition | Purpose |
| --- | --- | --- |
| `doc/sphinx/conf.py` | Enabled. | Sphinx build configuration and metadata. |
| `doc/sphinx/index.md` | Enabled. | Landing page and toctree, optionally reusing the README. |
| `doc/notes.md` | Enabled. | Initial documentation page with a customization TODO. |
| `doc/sphinx/Makefile`, `doc/sphinx/make.bat` | Enabled. | Build entry points. |
| `doc/api.md` | Enabled and API-package selection is nonempty. | Entry point for generated API reference. |
| `doc/<page>.md` | Enabled and Needs active, for each selected page. | Requirements/architecture/implementation/verification starter content. |

API/build output is generated by Sphinx, not hand-edited.

### Receiving targets

There are no receiving targets.

### Emitted contributions

| Target | Condition | Content |
| --- | --- | --- |
| `core.gitignore` | Enabled. | Documentation build ignore-pattern/comment lines. |
| `pyproject.dev_dependencies` | Enabled. | Quoted documentation dependency entries with trailing commas. |

The host must supply matching receiving files/targets and suitable dependency/runtime installation wiring for these integrations.
